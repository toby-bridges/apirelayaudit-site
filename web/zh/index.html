Local AI API Relay Security Audit

接入中转 API 前的本地安全审计

在把第三方中转端点接入编码工具前，先在本地整理出可复核的基线报告。执行探针时密钥仍会发给目标中转站，报告给出的风险汇总也不构成任何安全认证。

阅读中文上手指南 查看 GitHub

什么时候用

当你准备把第三方 AI API 中转站、Claude/OpenAI 兼容代理、coding agent 自动化或钱包相关流量放进生产环境前，用它生成一份可复查的 Markdown 报告。

检测什么

覆盖 token injection、prompt extraction、identity consistency signals、context truncation、tool-call rewriting、error leakage、SSE stream integrity 和 Web3 signature isolation probes。

不声称什么

它不为任何中转站颁发安全认证，也不替代人工安全审查。`inconclusive` 不是 `clean`，被拦截或无法判断的探针会保留在报告里。

查询意图边界

API relay audit

审计第三方中转站、镜像、网关、LLM proxy 或 resale API；默认使用 general profile。

Prompt injection audit

检测隐藏 prompt 注入、prompt 泄漏、指令覆盖和提取行为；主要覆盖 Step 3-6。

Model substitution signals

收集 self-ID、stream、latency 和 channel fingerprint 信号，但这些信号不能单独证明 provider 替换。

Web3 relay audit

钱包敏感场景使用 --profile web3 或 --profile full，Step 11 是 profile-gated。

常见问题

什么是 AI API 中转站（LLM proxy）？

夹在你和模型厂商（例如 Anthropic、OpenAI）之间的第三方服务。它把你的请求转发到上游，但也可能注入隐藏指令、替换模型、截断上下文、改写工具输出，或在报错响应里泄露凭据。详见 什么是 AI API 中转站。

审计时我的 API Key 会发到哪里？

审计在你自己的机器上运行，Key 只会发给你指定的中转站 URL，不会发给本站或任何额外的检测服务器。独立版 audit.py 是单文件、零 Python 包依赖，运行前可以先读一遍源码。建议用低额度、可随时撤销的专用测试 Key，通过 --key-env 从环境变量传入。

这里说的提示注入是什么？

指中转站在你的请求前面或中间塞入隐藏指令。工具会比较预期与实际的 token 用量、做提示词抽取探针，并在中转站疑似添加或泄露隐藏提示内容时记录证据。单条反常回答不构成结论，见 怎么检测提示注入。

报告里的 inconclusive 是什么意思？

表示工具无法判定该步是 clean 还是 anomaly。探针被拦截、格式不支持、回复含糊，都不会被当成安全；它们会保留在最终报告里，不并入 clean。

总评 LOW 就代表这家中转站安全吗？

不是。LOW、MEDIUM、HIGH 是本次已运行探针的风险汇总，不是安全认证；跳过和无法判断的步骤不等于通过。工具也不替代人工安全审查和线上监控。

跑一次会花钱吗？

探针请求会真实发给中转站，按中转站的规则计费或扣额度。先用 --connectivity 做低成本的连通性检查，再用 --skip-infra --skip-context 跑缩小范围的审计，步骤见 上手指南。

本站和禾维 AI、Veridrop 是什么关系？

三类工具各回答一个问题：哪几家值得看、给的是不是真模型、路上有没有人动你的请求。本站只答第三个：不排名、不推荐中转站、目前没有付费展示位，也不做返利外链。并列引用两家公开说法的对照见 工具怎么选。

我可以把报告公开或提交给你们吗？

报告只生成在你本机，本站不会收到它。原始 Markdown 和 JSON 不会自动脱敏，分享前请人工删掉密钥、私有端点、模型回复文本和个人信息。脱敏后的报告可以按 社区证据流程 提交，经维护者审核后才会进入公开登记处；登记处目前没有已发布条目。
