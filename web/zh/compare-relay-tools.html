中转站工具怎么选：三类工具各回答一个问题

买一家 AI API 中转站之前，你其实在问三个问题：哪几家值得看、它给的是不是真模型、路上有没有人动我的请求。禾维 AI、Veridrop 和 API Relay Audit 各答一个，谁也替代不了谁。本页把两家的公开说法原样引出来，附链接和日期，由你自己核对。

30 秒结论

你想知道去哪看什么
哪几家中转站值得放进候选禾维 AI按模型分的实测榜单里的在线率、延迟、输入价格，和站点档案
这家给我的是不是它声称的模型，高级能力有没有被剥离Veridrop每次检测的公开报告，和按域名聚合的红黑榜
路上有没有人往我的请求里塞东西、改我的工具调用、把 key 漏在报错里API Relay Audit（本站）你自己机器上跑出来的审计报告；inconclusive 单列，不并入 clean

顺序建议：先用禾维 AI 圈 3 到 5 家候选，再到 Veridrop 对每家跑一次真伪与能力检测，最后把剩下的用 API Relay Audit 在本地审一遍安全层，再决定充值和接入 agent。

两家的公开结果，我们怎么并列引用

三者回答的问题不同，互相补充，不互相替代。社区证据登记处的每一条，发布时会同时给出：

  • 被审域名、审计日期、代码 commit，以及脱敏后的原始记录；
  • Veridrop 按域名的红黑榜页（veridrop.org/leaderboard/<域名>）和禾维 AI 的站点档案页（hvoyai.com/sites/<域名去掉点>/）的链接，仅在两家对该域名确有页面时给出；
  • 一句说明：他们答"是不是真模型、能力全不全"和"在线率、延迟、价格怎么样"，我们答"路上有没有人动手脚"。

登记处目前没有已发布条目。提交与站长回应流程见 community-evidence.md。

他们怎么说对方

Veridrop 的对比页写："用 hvoy 比价、找候选站，用 Veridrop 做买前真伪核验" [10]，和本页的顺序建议一致。Veridrop 另有一页中转站检测工具横评，收录 11 款工具，其中没有 API Relay Audit [11]。禾维 AI 的首页与站长协议里没有提到 Veridrop，也没有提到本站 [1][2]。

边界

  • 本页不推荐任何中转站，也不为任何中转站颁发安全认证。
  • 两家的检测次数、收录数量等规模数字为其自述，本站未复核，因此不在本页转述。
  • 对两家的描述均附原文链接。若你发现与其官网不一致，请在 GitHub issue 里指出，本页会标日期更正。
