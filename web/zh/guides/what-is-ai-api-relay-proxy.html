什么是 AI API 中转站（LLM proxy）？

AI API 中转站，也叫 LLM proxy、API 代理、网关或镜像，是夹在你的应用和上游模型厂商（例如 Anthropic、OpenAI）之间的第三方服务。它可以转发请求、统一接口格式、计量用量或做路由，但它同样能改掉你收到的提示词、模型、上下文、流式输出或报错内容。

一句话：中转站是你模型供应链的一环。只要它能读写你的请求，就应该在生产流量或钱包相关流量依赖它之前先审一遍。

中转站能改什么

提示词路径

中转站可以在你的请求前面加隐藏指令、塞入身份文本、要求模型忽略用户指令，或者在后续回复里把隐藏的提示内容吐出来。

模型路径

中转站可以把请求转给另一个模型，却在 API 响应里写着你指定的模型名；也可能通过措辞或流式元数据泄露上游模型的身份。

工具路径

中转站可以在包安装命令或工具样式的输出到达 coding agent 之前改写它们，这就把代理行为变成了供应链风险。

为什么要在本地审计

网页版检测工具要求你先把中转站的 Key 交给另一个服务，才能测这个中转站。API Relay Audit 省掉了这一道额外的信任环节：脚本在你自己的机器上运行，你的 API Key 只会发给你指定的中转站 URL。

怎么审一遍

下载固定版本的脚本，先看帮助信息，再对目标中转站生成一份 Markdown 报告：

curl -fsSL https://raw.githubusercontent.com/toby-bridges/api-relay-audit/75bdac000051871c9f088a3be58e6f17a8854ffb/audit.py -o audit.py
python3 audit.py --help
python3 audit.py --key-env API_RELAY_AUDIT_KEY \
  --url https://relay.example.com/v1 --model YOUR_SUPPORTED_MODEL \
  --output report.md

命令里的 https://relay.example.com/v1 和 YOUR_SUPPORTED_MODEL 是占位符，执行时换成你获得授权的中转地址和它支持的模型代号。测试 Key 请用低额度、可随时撤销的专用 Key，放进环境变量 API_RELAY_AUDIT_KEY，不要写进命令行。探针请求会真实发给中转站，并可能按中转站的规则计费。分阶段的完整操作、连通性检查和报告脱敏，见 中文上手指南。

报告不能证明什么

一次看起来干净的运行不是合格证。中转站可以有条件地改变行为，模型的回答本身可能就模棱两可，不支持的格式会让某一步变成 inconclusive（无法判断）。把报告当成可复现的证据，而不是最终的安全标签。
